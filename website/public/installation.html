Installation howto

Install native XiriBSD first. Then run xiriprep on the installed system to prepare an IRIX desktop from your own donor image.

Before you start

The native installer provides NetBSD, the Xiri compatibility module, and the tools needed to import the desktop. The first login opens native ctwm. The original IRIX programs and fonts come from your own installed IRIX disk image afterward.

  • Prismatic, configured as an Indy with an R4400 or R5000 CPU, 256 MiB of RAM, and Newport graphics.
  • The installer xiribsd-indy-xiriprep-11.99.11.iso, found under .work/images/ in the Xiri checkout for the documented build.
  • A new, blank 6144 MiB raw disk for XiriBSD. The installer will format this disk.
  • For the IRIX desktop, a standalone CHD or raw whole-disk image of your own installed IRIX 6.5.22f or 6.5.30f system.

The same native installer serves both IRIX releases. Each installed system uses one donor release; keep a separate system disk for the other. The current qualification covers 6.5.22f on an R4400 and 6.5.30f on an R5000.

Already installed the earlier xiribsd-indy-native-11.99.11.iso? Keep your disk and follow the tools-CD route.

Install on a fresh Indy

Attach the disk and installer

Start Prismatic and pause the machine. Open F9 and set the following options:

LocationSettings
GeneralIndy; R4400 or R5000; 256 MiB RAM; default Newport graphics; Graphics console; PROM boot: Keep existing.
Media: SCSI ID 1Choose New disk…, select Raw, enter 6144 MiB, and choose a new filename such as xiribsd-indy.raw. Select Create disk and attach to draft.
Media: SCSI ID 6Attach xiribsd-indy-xiriprep-11.99.11.iso as the CD-ROM.

Boot the CD

Save with F9 and start with Ctrl + P. Click the guest display, press Esc during startup, and choose 5 — Enter Command Monitor. If the blank disk first reports “Unable to boot”, press Enter to reach the menu.

At the Indy PROM’s >> prompt:

boot -f scsi(0)cdrom(6)rdisk(0)partition(8)ip2xboot

The 6 matches the CD-ROM’s SCSI ID. If you attached it at ID 4, use cdrom(4) instead. The installer displays Newport’s black-to-green gradient.

Run sysinst

  1. Choose Install NetBSD to hard disk. Confirm that sd0 is your new 6 GiB disk before formatting it, then accept the default partition sizes.
  2. Choose Full installation and CD-ROM / DVD. If prompted for the set directory, enter sgimips/binary/sets. Wait for all 15 sets to unpack.
  3. Set the root password. In the configuration menu, set Enable xdm (X Display Manager) to YES and create your regular login account.
  4. Select Finished configuring, then Exit Install System. At the installer’s # prompt, enter halt and wait for the disk to unmount.

Boot the installed system

In F9 / Media, disconnect the CD at ID 6 and leave the disk at ID 1. Select F9 / General / PROM boot / NetBSD, save, and start the Indy. Choose Start System if the PROM menu appears.

For a manual disk boot, use the Indy PROM’s >> prompt:

setenv OSLoader boot
setenv OSLoadFilename netbsd.boot
setenv OSLoadOptions auto
boot

The installed kernel draws the SGI-style frame around the boot messages before xdm starts, even without an IRIX donor. The first boot builds the font cache. Log in at xdm with the account you created; you should reach a 1280×1024 ctwm desktop with a terminal.

This installer includes xiriprep. Continue to donor import to select the IRIX desktop for your account.

Use an existing Indy

If your disk was installed from the earlier xiribsd-indy-native-11.99.11.iso, add the tools without reinstalling. Boot that disk at SCSI ID 1. Attach .work/images/xiriprep-indy-desktop-tools.iso through F9 / Media / SCSI ID 6 / CD-ROM.

In a root shell inside the XiriBSD guest:

mkdir -p /cdrom
mount -r -t cd9660 /dev/cd0a /cdrom
(cd / && tar -xzpf /cdrom/xiriprep.tgz)
umount /cdrom

Eject the tools CD, then attach your donor media. The current xiribsd-indy-xiriprep-11.99.11.iso already includes these tools, so this extra step is only for the earlier installation.

Import your IRIX desktop

Run /usr/local/sbin/xiriprep as root inside XiriBSD. Supply the path to an image file on a mounted filesystem. In the examples, replace xiritest with the ordinary NetBSD login you want to prepare.

Use a complete donor export. If the IRIX installation lives in an emulator overlay, stop the emulator and export the merged disk first. A large raw base file can still contain an empty SGI volume header. See the donor export and profile guide.

Option A: CHD on a data CD

Create a data ISO with your standalone donor CHD. Choose a new output filename and replace the path after the equals sign. The file inside the CD will be named IRIX donor.chd.

On your workstation:

genisoimage -R -V OWNER_DONOR -o irix-donor.iso -graft-points \
  'IRIX donor.chd=/absolute/path/to/standalone.chd'

Attach irix-donor.iso to Prismatic’s CD-ROM slot, normally SCSI ID 6.

In the guest root shell:

mkdir -p /cdrom
mount -r -t cd9660 /dev/cd0a /cdrom
/usr/local/sbin/xiriprep --check --source '/cdrom/IRIX donor.chd' --user xiritest
/usr/local/sbin/xiriprep --source '/cdrom/IRIX donor.chd' --user xiritest

The optional --check identifies the release and reports the account status without changing the donor, account, or session. The command without --check performs the import. Once it reports that the desktop is selected, run umount /cdrom and eject the CD.

Option B: raw image on a second disk

The tested setup used a second disk at SCSI ID 2, with an FFS filesystem on /dev/sd1c containing the exported IRIX disk as a regular file. Use the device and filename that match your disk.

In the guest root shell:

mkdir -p /mnt/donors
mount -r -t ffs /dev/sd1c /mnt/donors
/usr/local/sbin/xiriprep --check --source '/mnt/donors/IRIX backup.img' --user xiritest
/usr/local/sbin/xiriprep --source '/mnt/donors/IRIX backup.img' --user xiritest

After a successful import, run umount /mnt/donors. The reader detects the format by content: either medium can contain a CHD or a raw whole-disk image. It reads the mounted file directly, including compressed CHD data.

Reboot and log in

The first import installs the shared desktop and fonts and prepares the native services. Remove the donor media and reboot before the selected account’s first 4Dwm login.

In the guest root shell:

shutdown -r now

Boot from the installed system disk and log in at xdm with the selected account’s usual credentials. On both tested Indys, 4Dwm opens at 1280×1024 with Toolchest, Icon Catalog, winterm, and xclock.

To check the Screen Saver, open its control panel, select Qix, and click Demo. Press Space to return. A user who kept the default XiriBSD session still gets ctwm.

Read the qualification results and screenshots for both releases.

Accounts and storage

  • Existing account: its native home and password are preserved. A previous ~/.xsession is saved as ~/.xsession.before-xiriprep; repeating the command preserves that backup. Restore it to return to the previous session. Other logins keep their current desktops.
  • Missing account: after identifying the donor, xiriprep offers to create the user. The default is No. If you choose Yes, it creates an ordinary user with home /usr/people/<login> and prompts for a password. Create the account beforehand for non-interactive use.
  • Another user: repeat xiriprep with the intended login. A matching shared installation is reused.
  • Another IRIX release: use a separate system disk. Do not combine the 6.5.22f and 6.5.30f donor installations.

The reader verifies the required executables, libraries, fonts, resources, and catalog links in private staging directories before publishing the desktop. Allow the following free space:

Filesystem containingFree space
/var/db192 MiB
/emul184 MiB
/usr/local/share/xiri8 MiB

The shared desktop lives at /emul/irix and its fonts at /usr/local/share/xiri/fonts. On a typical single-filesystem Indy install, the staging tree is renamed into place. If verification fails, correct the donor or free the requested space and rerun.

Browser, freeware, and audio packages have separate installation instructions. Independently installed donor layouts need further qualification; the tested reference donors do not establish compatibility with every IRIX installation.

Build the media

Developers can build the native ISO from the Xiri checkout on a Linux workstation. The documented requirements include Python 3.11+, Git 2.38+, CMake 3.19+, genisoimage, isoinfo, C and C++ compilers, the NetBSD cross-build prerequisites, and access to the pinned libchdr, FAM, and pkgsrc sources.

On the workstation, from the Xiri checkout:

scripts/build-xiribsd-iso.py --work .work/native-indy \
    --output .work/images/xiribsd-indy-native.iso

The output filename is selectable. When using this example, attach the generated xiribsd-indy-native.iso as the installer CD in the fresh-install steps above.

The builder records its source revisions and recipe hashes in .work/native-indy/sources.json and reuses that lock on retry. Archive it alongside the ISO. For the qualified installer with on-target desktop import, use the desktop installer lock with the Xiri recipe revision recorded in its xiri field, passing the lock file with --lock.

See the full build instructions for source preparation, toolchain reuse, and Toolbox options.

Rebuild the tools CD

On the workstation, from the Xiri checkout:

python3 scripts/package-xiriprep-tools.py installer.iso tools.iso

Use a current installer for installer.iso and a new output path for tools.iso. The installer and tools CD contain native components and release inventories. The original IRIX desktop comes from the owner’s donor. The installed reader’s source archive is /usr/local/share/xiri/xiriprep-source.tgz.
